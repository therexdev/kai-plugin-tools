# KAI Tools

Restores the original Koinos AI Tools & accounts screen, MCP catalog and custom servers, trust controls, Node runtime setup, email and calendar configuration and actions. Developer tools retain the original enable switch, multi-agent builder, saved teams, human-input playground, custom pipelines and objective benchmark. Local models run through Core; network teams use the original total credit budget and saved-result review. The feature opens in its own installed plugin window.

Requires KAI Core 0.5.0 or later. Original rendering assets are identified in ORIGINAL_UI.json. Native requests are scoped to this feature; permissions, privacy settings and native reviews still apply. Saved original feature data remains in the shared KAI profile.

Run `npm test`. Packages are signed with the existing KAI publisher identity.
