Developer Tools

Build and run your own agent systems on this machine's API — from a one-line pipeline to a team of named agents that talk, use tools, and ask you questions.

Named agents share one conversation. Pick how the floor moves — round robin, a model moderator, or explicit handoffs — and how it ends. A human agent pauses the run and asks you. Hard ceilings always hold: 60 messages, 120 model calls, 6 tool actions per turn. Apps can POST the same spec to /core/agents/run.
